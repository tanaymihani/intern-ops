Refresh a login

Handshake and JobRight are searched as you. When the Sources panel says a login expired, renew it here from any computer — no app or command line needed.

  1. In Chrome, sign in at app.joinhandshake.com (Northeastern SSO) and stay on the job search page.
  2. Open DevTools (Cmd+Option+I on Mac, F12 on Windows) → Network tab, type graphql in the filter box, then click any filter or scroll the results so a request appears.
  3. Right-click a graphql request → Copy → Copy as cURL, and paste it below.
  1. Sign in at jobright.ai (set your preferences to Internship + ML / quant roles).
  2. DevTools → Network, filter swan, refresh the page.
  3. Right-click a swan-api.jobright.ai request → Copy → Copy as cURL, and paste it below.

Only the login cookie is kept, encrypted, in this site's private storage; the scheduled GitHub job picks it up on its next run.
