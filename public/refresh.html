Refresh JobRight session

When the Sources panel says JobRight needs sign-in, your session expired. Steps:

  1. Log into jobright.ai in your normal browser (set your job preferences to Internship + ML / quant roles so recommendations match).
  2. Open DevTools (Cmd+Option+I) → Network, filter for swan, and refresh the page.
  3. Right-click a request to swan-api.jobright.ai → Copy → Copy as cURL, and paste it below.

The cookie is sealed with your repository's public key and stored as the JOBRIGHT_COOKIE GitHub Actions secret. It isn't saved anywhere else.
